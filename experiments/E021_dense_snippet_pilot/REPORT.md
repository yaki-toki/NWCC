  - C − R1에는 두 지표·두 파이프라인 모두 z ≤ −1인 설정이 없다. 그래서 NO-GO가 아니다.
  - C − R0는 V-AUC에서 나쁨형이 아니다(z ≤ −1인 설정이 L20 1개, M10 2개; 나쁨형은 3개 이상). 그래서 보류(재추출 손해)도 아니다.
  - C − R0의 비열등이 실패해 GO도 아니다. 그래서 "그 밖"의 보류다.
- 계획의 쓰임: 보류이므로 선택은 사용자가 한다. 사용자는 시간 주석 진단(`describe`) **뒤**에 선택지 (i) "확인 계획 작성"을 골랐다("(i) 확인 계획 작성 (추천, Jev 0.92)", 2026-10-12 13:27). 시험 영상은 추출하지 않았다.
- 붙은 표지: 재추출 효과(두 파이프라인), 개수 의존(두 파이프라인), 길이 지름길 가능, δ 유효성((팔·파이프라인·데이터셋) 8개), 수렴 교란(헤드 6개). 한 데이터셋에만·영상 수준 채택형·파이프라인 의존·극값 판독 민감은 붙지 않았다. 수치 실패는 없다.
- 단위
  - V-AUC는 교차 맞춤 V-AUC(단계 2 epoch 1–30, UCF R = 1000, XD R = 200)의 개발 seed 0·1·2 평균이다. "포인트"는 AUC × 100이다.
  - z = Δ / δ다. δ는 계보 값으로, L20은 E010(UCF 0.1091, XD 0.0488포인트), M10은 E018(UCF 0.1774, XD 0.0287포인트)이다.
  - z^LS = Δ^LS / δ^LS다. δ^LS는 R0의 6-seed SD로 정했다. 주 판독에서 L20은 UCF 0.2209·XD 0.0824포인트, M10은 UCF 0.1777·XD 0.0491포인트다(`ls_thresholds`).

  - (1단계) 지금 헤드가 모든 스니펫을 채점하는 경우(A0)와 (2단계) 32구간 평균으로 학습하고 스니펫마다 채점하는 경우(C)를 본다.
  - 둘이 지금의 32클립 파이프라인보다 검증의 영상 수준 구별(길이 층화 포함)에서 L20·M10 모두 해롭지 않은지, 추출·파생이 올바른지 묻는다.
  - E021이 보일 수 있는 것은 많아야 "영상 수준에서 해롭지 않고 추출·파생이 올바르다"이다. 국소화 개선과 XD 격차는 묻지 않는다. 같은 특징 비교 기법과의 비교는 로드맵 F2로 미뤘다.

- 판정 규칙
  - 비열등 NI: 두 데이터셋 각각에서 두 특징 쌍 z의 평균이 −1보다 크고, 설정마다 z가 −2보다 커야 한다.
  - 나쁨형: 4개 설정 가운데 3개 이상에서 z ≤ −1이다.
  - 1단계 NO-GO: 어느 파이프라인에서든 A0 − R1v가 V-AUC·LS-AUC 모두 나쁨형이고, 이것이 두 판독에서 모두 성립해야 한다.
  - 최종 판정(위에서부터 처음 맞는 것)
    1. NO-GO: 어느 파이프라인에서든 C − R1이 V-AUC·LS-AUC 모두 나쁨형
    2. 보류(재추출 손해): 어느 파이프라인에서 C − R0가 V-AUC 나쁨형이고 C − R1은 V-AUC 나쁨형이 아님
    3. GO: 모든 관문 통과, 수치 실패 없음, 두 파이프라인 모두에서 C − R1·C − R0가 두 지표 모두 비열등
    4. 보류: 그 밖
  - 판독 민감: 로짓 판독으로 다시 계산한 범주(GO / 보류 / NO-GO)가 주 판독과 다르면 보류(판독 민감)다. 극값 판독 민감(C를 G로 읽음)은 표지일 뿐 판정을 바꾸지 않는다.

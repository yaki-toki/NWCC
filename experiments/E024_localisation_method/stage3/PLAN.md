# E024 2·3단계 — UBnormal 준비와 확정 (초안; 고정 전)

상위 계획: [`../PLAN.md`](../PLAN.md) (2단계 "새 벤치마크 준비", 3단계 "확정", 2026-10-25·26 변경 기록의 확정 결정). 1단계 결과: [`../stage1/PLAN.md`](../stage1/PLAN.md) 변경 기록(후보 `k_rg_t0.25`, `final_control` = C6 trainonly).

## 이 계획의 성격 (공개)
- 사전등록 확정이다. UBnormal 시험셋은 이 저장소와 이전 프로젝트 어디서도 읽은 적이 없다(첫 읽기). UCF-Crime·XD-Violence 시험셋은 네 번째 읽기이며 **보조 읽기**다(판정에 쓰지 않음; 상위 계획 D2).
- 판정은 UBnormal 하나에서, 사전 고정한 두 대비의 95% 하한으로 한다. 크기 조건·합산 지표 조건·SOTA 근접 조건은 없다(2026-10-25 14시 사용자 지시).
- 1단계는 개발 선택이었고 향상의 증명이 아니다. 향상의 증명은 이 단계에서만 한다. 확정 실패도 그대로 보고하며, 지표·통제·seed·데이터셋을 바꿔 반복하지 않는다.
- 사용자 지시(2026-10-26): "실험 수정이나 재학습 없이 UBnormal 확정 단계로 넘어가면 됩니다." 1단계 결과·코드·선택은 바꾸지 않는다.

## 고정 전에 알고 있던 사실 (공개)
- UBnormal(Acsintoae 등, CVPR 2022; arXiv 2111.08644): 합성(Cinema4D) 영상 543개, 장면 29개, 프레임 236,902개. 공식 분할(저장소 `scripts/*_video_names.txt`, 2026-10-26 확인): 학습 정상 186 + 이상 82 = 268, 검증 26 + 38 = 64, 시험 53 + 158 = 211. 영상 이름 `{normal|abnormal}_scene_<s>_scenario_<k>[_<j>]`, 파일 `Scene<s>/<이름>.mp4`. 이상 영상의 정답은 `Scene<s>/<이름>_annotations/<이름>_tracks.txt`(행마다 `[object_id, start_frame, end_frame]`, 끝 프레임 포함)와 프레임별 마스크 PNG. 프레임 정답은 공식 스크립트 `write_frame_level_ground_truth.py`처럼 tracks의 [start, end] 구간을 1로 둔다(마스크는 쓰지 않음). 라이선스 CC BY-NC-ND 4.0: 지표만 공개하고 유도 특징·점수 파일은 배포하지 않는다.
- 보관 파일: `UBnormal.zip` 16,037,804,331 바이트(mp4 543, png 236,902, txt 279; Python zipfile 중앙 디렉터리 확인 2026-10-26). sha256은 입력 기록에 적는다.
- 열린 집합 벤치마크다. 학습 이상 유형과 시험 이상 유형이 다르다. 약지도 프레임 AUC 보고치가 52–64 수준이라 UCF·XD(검증 V-AUC 0.95–0.99)와 양상이 다를 수 있다. UBnormal에는 glance 점이 없으므로 개발 지표(GP)는 없고, 이 단계에는 개발 결정이 없다.
- 1단계 실측 잡음(검증, GP): 후보 K − U의 영상 부트스트랩 SE UCF 0.17 / XD 0.19, seed SD 0.45 / 0.44; K − C6의 seed SD 0.45 / 0.67. E023 시험 L의 영상별 짝 차이 SD 약 8.8(UCF, URDMU 대 C).

## 검출력 (고정 전 계산; 참고값)
- UBnormal 이상 시험 영상 158개(한 부류만 있는 영상은 L에서 빠지므로 실제 n은 기록에 적음). 영상별 짝 차이 SD 8.8을 가정하면 영상 SE ≈ 8.8/√158 ≈ 0.70 L포인트. seed 성분은 1단계 GP seed SD(0.45–0.67)를 L에 그대로 옮긴 가정으로 3 seed에서 0.26–0.39 → 결합 SE ≈ 0.75(P − U) / 0.80(P − C6).
- 두 대비 각각 95% 하한 > 0이려면 점추정이 대략 1.5–1.6 L포인트 이상이어야 하고, 검출력 0.8의 최소 검출 효과는 약 2.1–2.2 L포인트다. 두 대비 모두를 요구하므로 결합 검출력은 그보다 낮다(상관이 양이면 덜 낮아짐). 1단계 XD의 K − U GP +1.40, K − C6 +0.90은 이 크기보다 작거나 비슷하다. **"미충족"이 충분히 그럴듯한 결과임을 미리 적는다.**
- 다중성 보정은 하지 않는다(사용자 결정: 95% 하한 > 0, Holm 폐기). 두 대비는 한 가족으로 보고하되 각각의 하한을 쓴다.

## 팔 (UBnormal; UCF·XD 4번째 읽기도 같은 세 팔)
| 팔 | 내용 | 1단계 대응 | 새 사슬 |
|---|---|---|---|
| P | URDMU + K(ρ 전역, τ 0.25), `--mode k --rho g --tau 0.25` | 후보 `k_rg_t0.25` | 2쌍 × seed 3·4·5 = 6 |
| U (= P − K) | URDMU 공식 기본, 같은 초기화·데이터 순서(관문 (k0) 성질) | 0a U | 6 |
| C6 (= P − K + 통제) | trainonly(ρ 전역, τ 0.25): 학습 때만 K, 채점은 z | `ctl_trainonly_rg_t0.25`, `final_control` | 6 |

- 쌍(특징): `xcb_xcl`, `xcb_siglip`(1단계와 같음). UBnormal 특징은 2단계에서 같은 추출기로 만든다.
- **seed 3·4·5**(새 seed; 1단계 개발 seed 0–2는 쓰지 않음). 세 팔은 seed마다 같은 초기화·데이터 순서에서 갈라진다.
- 학습 설정은 1단계 K 명령과 같다(unit 200, n_chunk 4096, 결정 모드, 평가 점 30, Adam + L2). UBnormal 전용으로 바꾸는 것은 데이터셋 등록(2단계)과 아래 "학습률 점검"의 배율 하나뿐이다.
- MIL·RTFM·VCV 팔은 UBnormal에서 돌리지 않는다(상위 계획 2026-10-25: B*는 URDMU; 비교 기법은 E023 결과를 인용).
- UCF·XD 4번째 읽기: 같은 세 팔, 4설정(2 데이터셋 × 2쌍) × seed 3·4·5 = 36사슬. 결과는 보조 읽기로만 보고한다(비독립 읽기 표지).

## 체크포인트와 채점
- 1단계와 같다. 30개 평가 점에서 검증 영상 AUC(V-AUC, 영상 레이블만)가 가장 높은 점(동률은 앞), P는 s = z + k, C6은 z, U는 z의 V-AUC로 고른다. σ 판독으로 선택, 로짓 판독으로 평가.
- UBnormal 검증은 공식 64개(정상 26, 이상 38). 검증 프레임 레이블은 선택·판정에 쓰지 않는다(2단계의 파서 형식 확인에만 씀, 아래).
- 시험 채점은 봉인 뒤 명령 하나로 세 팔·두 쌍·세 seed의 선택 체크포인트를 한 번에 채점한다(아래 "시험 접근").

## 지표
- **L**: 이상 시험 영상마다 그 영상 프레임만으로 프레임 AUC(UBnormal; UCF도 AUC, XD는 AP), 같은 무게로 평균. 모든 프레임이 한 부류인 영상은 빼고 수를 적는다. 스니펫 로짓을 받침 프레임에 복사.
- 공개 항목(판정 아님): 프레임 AUC(모든 시험 영상 합산; UBnormal 표준 프로토콜), 프레임 AP, 이상 영상만의 AUC_A, 팔별 V-AUC(검증), 붕괴·수치 실패 수, 길이 삼분위별 L.
- 기술(학습 없음): P의 선택 체크포인트를 k = 0으로 재채점한 I2(1단계 `rescore`와 같은 코드)와 K − I2, I2 − U.

## 통계와 판정 (사전 고정)
- 짝짓기: 같은 (쌍, seed)의 P·U·C6은 한 짝. 영상 v, seed s, 쌍 p의 L을 쌍에 대해 평균한 뒤 Δ_{v,s} = L_v(P) − L_v(B)(B ∈ {U, C6}). 두 팔 모두 유효한 seed만 쓴다(교집합; 1단계 M4).
- **주 구간**: 영상 × seed **교차(crossed)** 계층 부트스트랩(`glance.bootstrap_draws`·1단계 민감도 구간과 같은 방식): 재표본 r마다 이상 시험 영상의 복원 추출 횟수 w[r, v]와 seed의 복원 추출 횟수 m[r, s]를 각각 한 번 뽑고(영상 묶음 → seed 묶음 순서, `glance._draw_counts`), 재표본 값은 Σ_v Σ_s w[r, v] m[r, s] Δ_{v,s} / (Σ_v w[r, v] · Σ_s m[r, s]). seed는 모든 영상이 공유하는 사슬 수준 요인이므로 영상마다 seed를 따로 뽑는 중첩(nested) 방식은 쓰지 않는다(seed 성분이 평균돼 구간이 좁아짐). R = 2000, `np.random.default_rng(20261026)`, 95% 백분위 구간(행 1–R; 행 0은 표본). 점추정은 전체 평균.
- **성공 기준**: UBnormal에서 P − U와 P − C6의 95% 하한이 **모두 > 0**. 크기 조건 없음. 하나라도 ≤ 0이면 미충족.
- 함께 적는 것(판정 아님): 영상만 재표본한 95% 구간(seed 평균 고정), seed별 점추정 3개, 쌍별 점추정, 합산 지표의 P − U·P − C6 구간.
- UCF·XD 4번째 읽기는 같은 통계로 계산해 "보조·비독립" 표지로 보고한다. 판정에 넣지 않는다.
- 결과 행(위에서부터 먼저 맞는 행)

  | 결과 | 행 | 다음 |
  |---|---|---|
  | 관문 실패·판정 없음(두 팔 모두 유효 seed 0) | `no_verdict` | 보고하고 사용자 결정 |
  | 두 하한 모두 > 0 | `met` | 원고 결과·주장 작성(아래 "결과의 쓰임") |
  | P − U만 > 0 | `partial_u` | 미충족. 원고에는 "URDMU 대비 양, C6 대비 불확정"으로 적고 K의 추론 시 이점은 주장하지 않음 |
  | P − C6만 > 0 | `partial_c6` | 미충족. 원고에 그대로 적음 |
  | 둘 다 ≤ 0 | `not_met` | 미충족. 그대로 보고; 사용자 결정 |

- 해석 문구(사용자 지시 2026-10-26을 시험에도 적용): 하한이 0을 넘지 않는 대비는 "차이 불확정"이며 "추론 시 K를 사용하는 추가 이점은 확인되지 않았다"(P − C6), "K의 이점은 확인되지 않았다"(P − U)로 한정한다. 상한이 0 아래인 대비는 "열세"로 적는다. 원인은 단정하지 않는다.

## 붕괴와 실패 (2단계 개발 seed 실행으로 수치를 채움)
- E023의 "σ 선택 V-AUC < 0.60"은 V-AUC 0.95–0.99인 데이터셋에서 정한 값이라 그대로 쓰지 않는다. **규칙(형태 고정)**: 2단계에서 U를 개발 seed 0–2 × 2쌍(6사슬)으로 UBnormal 검증에 돌려 σ 선택 V-AUC의 중앙값 m_U를 잰다. 붕괴 문턱 = 0.5 + ½·(m_U − 0.5)(우연과 m_U의 중간). 이 수치를 고정 전에 아래 "입력 기록"에 적는다. 3단계 사슬의 σ 선택 V-AUC가 문턱 아래면 그 사슬은 붕괴로 기록하고 짝에서 빠진다(교집합 seed).
- 수치 실패(비유한 손실·NaN 점수)는 1단계처럼 멈추고 보고한다(같은 명령으로 1회 재실행은 인프라 실패에만).
- 학습률 점검(상위 계획 D4, 검증만): 2단계 U 사슬에 lr·척도 배율 {0.5, 1, 2}를 적용해 σ 선택 V-AUC 평균이 가장 높은 배율을 세 팔 모두에 쓴다(동률은 1). 배율 1이 아닌 값이 뽑히면 그 사실과 수치를 공개한다. 이 점검은 U에만 하고, P·C6에는 같은 배율을 그대로 쓴다(개발 선택 금지).

## 2단계 — 준비 (시험 값을 열지 않음)
1. 보관 파일 검증: 로컬·서버 sha256 일치, 항목 수(543/236,902/279), 라이선스 파일 sha256. 풀기(서버 `/data2/jhkim/raw/ubnormal/UBnormal/`), 원본 zip은 해시 대조 뒤 삭제(저장 공간).
2. 접근 유형 (0): 영상 목록·헤더(프레임 수·fps·해상도)·sha256만 읽는다. 시험 영상도 같다. 접근 기록에 남긴다.
3. 정답 구조 (0g-ubn): 검증 이상 영상 38개의 tracks로 파서를 확인한다(행 형식, 0 ≤ start ≤ end < n_frames). 시험 이상 영상 158개의 tracks는 **존재·sha256·행 수만** 읽고 값은 열지 않는다. 시험 매니페스트에는 이름·레이블·프레임 수·fps만 넣고, 구간은 봉인 뒤 시험 채점 명령이 tracks를 읽어 쓴다(E020·E023의 매니페스트 구간 사전 적재와 다른 점을 공개한다. 이 벤치마크는 레이블이 영상별 파일이어서 그렇게 할 수 있다). 파싱 실패 영상은 평가에서 빼고 이름을 기록한다(사전 등록 처리).
4. 분할 파일 `data/splits/ubn_val_official.json`: 학습 매니페스트(학습 268 + 검증 64 = 332, 공식 목록 순서)에서 공식 검증 64개의 색인. `split_sha256`을 적는다. 근접 중복 점검(상위 계획 (0d))은 합성 영상이라 하지 않는다.
5. 특징 추출: 세 인코더(xcb, xcl, siglip)로 조밀 16프레임 스니펫, 학습·검증·시험 543개 전부(`wvad.extract dense`; 시험 영상의 특징 추출은 픽셀만 읽는 접근으로 기록). 학습·검증에는 `d16m200` 창 행을 만든다(`derive`). 시험은 조밀 저장소만.
6. 데이터셋 등록 `ubn`과 **회귀 관문**: 기존 UCF·XD 경로의 출력이 바뀌지 않았음을 (a) `pytest tests` 전부 통과, (b) 1단계 후보 사슬(UCF·XD 각 1개, seed 0)의 `rescore` 관문 (s) 비트 일치, (c) 커밋된 1단계 결과 파일을 새 코드의 `analyze`로 다시 계산해 JSON이 같음(해시 비교)으로 확인한다. 등록 코드는 코드 독립 검토(변경 부분만)를 받는다.
7. 라이선스 기록 `results/e024_licences.json`(UBnormal CC BY-NC-ND 4.0, 출처 URL·커밋, 분할 목록 sha256, 배포하지 않는 산출물 목록).
8. 개발 seed U 사슬 6개(+ 학습률 점검 배율 0.5·2의 12개)로 붕괴 문턱과 배율을 정한다(검증만). 결과를 입력 기록에 적고 이 절의 수치를 채운 뒤 **봉인**한다.

## 시험 접근 (봉인 뒤 한 번)
- 봉인(`stage3/PLAN.sha256`, 단독 커밋) → 서버 배포(`DEPLOYED_COMMIT` 일치) → 학습 54사슬 → 관문 → **시험 채점 명령 1회**(세 팔 × 두 쌍 × 세 seed의 선택 체크포인트; UBnormal 먼저, 그다음 UCF·XD) → 로컬 분석 → 결과 커밋. 시험 점수 파일은 저장소 밖에 둔다.
- 시험 결과를 본 뒤 바꾸지 않는 것: 팔, seed, 통계, 성공 기준, 통제(C6), 해석 문구 규칙.

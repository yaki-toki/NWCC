## 실험 폴더에 들어가는 것
| 파일 | 언제 | 내용 |
|---|---|---|
| `PLAN.md` | 실행 전 | 질문, 바꾸는 것 하나, 고정 조건, 셀과 seed, 측정 지표, 채택 문턱, 판정 규칙. 실행 뒤에는 고치지 않고, 바뀐 점은 맨 아래 변경 기록에 시각·이유와 함께 덧붙인다. |
| `PLAN.sha256` | 실행 전 | `PLAN.md` 고정본의 해시(고정 커밋은 이 파일만 더하는 커밋) |
| `results/` | 실행 후 | seed별 원자료 CSV, 집계 CSV/JSON, 관문·환경·접근 기록(작은 파일만) |
| `REPORT.md` | 실행 후 | 결과, 판정, 한계, 다음 단계 |
| `logs/` | 실행 중 | 원본 로그. git에 올리지 않음(`.gitignore`) |

## 규칙
1. **시험셋.** 시험셋은 사전 등록된 확정 실험에서만, 한 번만 읽는다. UCF-Crime·XD-Violence는 E022·E023·E024 보조 읽기까지 세 번 읽혔고(비독립), UBnormal은 E024 3단계에서 한 번 읽혔다.
2. **선택.** 체크포인트·헤드·임계값·하이퍼파라미터는 검증 분할로만 고른다.
3. **seed.** 개발 seed와 확정 seed를 섞지 않는다.
4. **실패 기록.** 실패하거나 중단한 실행은 보고서에 횟수와 이유를 적고, 실행 상태 요약은 `results/`에, 원본 로그는 git 밖에 둔다.
5. **판정 규칙 고정.** 결과를 본 뒤 판정 규칙을 바꾸지 않는다. 사후 분석은 별도 폴더에 두고 판정과 섞지 않는다.

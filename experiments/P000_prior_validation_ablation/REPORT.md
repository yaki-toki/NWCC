# DCRC-VAD 절제 보고서 (임시 명칭 검증)

작성 2026-10-02 · 사전등록 `submission/tcsvt2026/records/PREREG_DCRC_ABLATION_20261002.md` (고정본 sha256 `29fd8801…`, 학습 시작 전 고정; 결과 확인 뒤 운영 사실 3건을 변경 기록에 추가, 판정 규칙 변경 없음) · 원고(`main_tcsvt.tex`)는 손대지 않았다 · 독립 검증(별도 코드로 전 대비 재계산): 판정·명칭·보조 분기 결론 재현, 지적 9건 반영.

> **판정: NO-GO.** 같은 헤드·같은 2단계 학습 일정의 기본 모델(B) 대비 개선은 검증 최고 체크포인트에서 4설정 중 2개(UCF-Crime)에서만 유의하다. 사전등록 기준은 3개 이상이다. XD-Violence 두 설정에서는 Holm 보정 후 유의하지 않다. 조밀 순위 손실(TC-MIL)의 효과는 모든 설정에서 0에 가깝고, 개선은 전부 의사 레이블 자기학습(CPL)에서 나온다. 커리큘럼과 보조 분기도 검증 최고 규칙에서 탐지를 개선하지 않는다. 따라서 `DCRC-VAD`라는 약어는 채택하지 않는다.

## 1. 확인한 질문
- 이 방법을 조기 인식이 아니라 새로운 약지도 영상 이상 탐지(WVAD) 방법으로 내세울 수 있는가. 구체적으로, 핵심 두 구성요소(TC-MIL, CPL)가 각각 또는 함께 성능을 일관되게 올리는가를 다음 조건에서 확인했다.
  - 체크포인트는 검증 분할만으로 고른다.
  - 두 데이터셋과 두 특징 쌍 모두에서 확인한다.
- 보조 분기(방송 영상 레이블 위험 헤드)가 탐지에 필요한가.
- 이름이 실제 동작과 맞는가.

지킨 원칙은 다음과 같다.
- 시험셋으로는 아무것도 고르지 않았다. 체크포인트·헤드는 검증 분할로만 골랐고, 임계값은 쓰지 않았으며, 하이퍼파라미터는 새로 고르지 않았다.
- 새로 학습한 360회의 체크포인트는 학습이 모두 끝난 뒤(10:16 UTC 이후) 평가기로 한 번만 시험셋에 적용했다.
  - 예외는 10절 재현성 점검의 이전 체크포인트 재채점이다. 이 재채점은 학습 도중(04:59–05:10 UTC)에 시험셋을 읽었다.
  - 대상은 이미 시험 평가된 적 있는 이전 실행이며, 어떤 선택에도 쓰지 않았다.
- 이전의 시험셋 선택 결과는 섞지 않았다.
- 조기 인식·예측·위험 예측에 관한 주장은 하지 않는다. horizon-risk NO-GO 결과는 다루지 않았다.

## 2. 실험 설계 (사전등록 요약)
| 항목 | 값 |
|---|---|
| 데이터셋·특징 | UCF-Crime, XD-Violence × 동결 XCB+XCL(1792차원), XCB+SigLIP(1920차원) = 4설정 |
| 검증 분할 | 학습 영상 15% 범주 층화(UCF 241개, XD 592개), 기존 검증 프로토콜과 같은 파일 |
| seed | 10개 공유(42, 123, 777, 1000, 2025, 7, 13, 99, 555, 31337) |
| 학습 | 1단계 MIL 20 epoch(lr 1e-4) → 2단계 3회×10 epoch(lr 3e-5), AdamW, 1단계 검증 최고로 2단계 시작 |
| 체크포인트 | 주 규칙 = 검증 최고(2단계 epoch 중 검증 영상 AUC 최대), 보조 규칙 = 고정 예산 마지막 |
| 하이퍼파라미터 | 기존 코드값 그대로(새로 고르지 않음, 11절 한계 참조) |

| 셀 | 2단계 목적함수 | 비고 |
|---|---|---|
| B 기본 | MIL만 (TC 0, 의사 레이블 0) | 원고의 "schedule-only" 대조와 같은 셀 |
| T | B + 조밀 순위(TC-MIL) | |
| C | B + 의사 레이블(CPL: 상위 구간 양성·하위 구간 음성, 커리큘럼) | |
| F | B + TC + CPL | 보조 분기 없는 기존 방법 |
| F−커리큘럼 | F에서 커리큘럼만 끔(고정 top-k 4, 신뢰도 0.55) | 명칭 확인용 |
| 보조 4종 | F + 보조 헤드 {1개, 3개} × {BCE, 증거 손실} | 3헤드 증거 = 원고 방법 |

같은 (특징, seed)의 B/T/C/F/F−커리큘럼은 1단계 체크포인트를 공유한다. 따라서 셀 간 차이는 2단계 목적함수에서만 나온다.

통계는 다음과 같이 계산했다.
- seed 짝 차이와 부트스트랩 95% 구간(10,000회), 효과크기 d_z
- 주 검정은 짝 t검정, 민감도 확인용으로 정확 부호 뒤집기 검정
- 사전등록한 계열별로 Holm 보정

용어:
- **지지됨**: Holm 보정 p < 0.05이면서 구간이 0을 포함하지 않는 경우
- **일관됨**: 4설정 중 3개 이상에서 양(+)으로 지지되고, 음(−)으로 지지된 설정이 없는 경우

## 6. 결과 3 — 왜 이렇게 나오나 (해석 근거)
- **TC-MIL이 사실상 꺼져 있다.**
  - 2단계 손실에서 TC 항은 MIL 손실 안에서 0.05로 곱해지고, MIL 손실 전체가 다시 0.1로 곱해진다(`train_ucf_pseudo.py` 432행, 456–461행).
  - 그래서 전체 손실에서의 실효 가중치는 0.005다. CPL 셀에서는 의사 레이블 손실(1.0)의 1/200이다.
  - MIL만 쓰는 T 셀에서는 같은 MIL 손실 안의 최댓값 순위 손실(가중치 1)의 1/20이다. Adam은 손실 전체 배율에 거의 무관하므로 이 상대 비중이 의미가 있다.
  - 이 작은 가중치는 측정된 효과(단독 |Δ| ≤ 0.04 AP, CPL 위에서 ≤ 0.11)와 맞는 설명이다. 다만 TC 손실 값이나 기울기 비중을 직접 재지는 않았다.
  - 더 큰 가중치에서 효과가 있는지는 이 실험이 답하지 않는다. 확인하려면 새 하이퍼파라미터 탐색이 필요하고, 검증 전용으로 사전등록해야 한다.
- **검증 최고 규칙은 의사 레이블의 첫 회차만 고른다.**
  - CPL을 쓰는 셀(C, F, F−커리큘럼)은 두 데이터셋의 120회 모두에서 2단계 epoch 1–10(첫 회차) 안의 체크포인트가 선택되었다. 중앙값은 UCF 4–5, XD 1–2다.
  - 커리큘럼은 회차별로 상위 구간 수·신뢰도 문턱을 1회차 3/0.65, 2회차 4/0.58, 3회차 5/0.50으로 바꾼다. 고정 설정은 4/0.55다.
  - 따라서 검증 최고 규칙의 커리큘럼 대비(C7)는 사실상 "1회차 3/0.65 대 고정 4/0.55"의 비교다. 상위 구간 수를 늘려 가는 후반 단계는 선택된 모델에 반영되지 않는다.
  - 마지막 규칙에서 CPL이 AUC를 낮추는 것과 같은 방향의 관찰이다. 후반 회차를 거친 모델은 검증에서 선택되지 않았고, 시험에서도 AUC가 낮다.
- **기본 모델이 이미 대부분의 성능을 낸다.**
  - 같은 헤드·같은 일정의 B가 검증 최고에서 UCF 25.6/26.4, XD 72.5/73.8 AP를 낸다.
  - F와의 차이는 UCF +1.2/+2.4, XD +0.5/+0.8 AP다.

## 9. 명칭 검증
- **TC-MIL은 `dense normal-to-anomaly ranking loss`(조밀 정상-대-이상 순위 손실)로 이름을 바꿔야 한다.**
  - 코드(`sear/loss/mil.py: temporal_contrastive_mil_loss`)는 순위 손실이다. 각 이상 영상의 최고 구간 점수와, 같은 묶음 안 모든 정상 영상의 모든 구간 점수 사이에 여유 0.5의 hinge를 건다.
  - 시간 순서나 시간적 대비는 쓰지 않는다.
  - 단위 시험(`scripts/dcrc/test_dcrc.py`)으로 확인했다. 영상 안 구간 순서와 정상 구간 전체 배치를 섞어도 손실 값이 같고, 위의 명시식과 정확히 일치한다. 2단계 학습기도 같은 함수를 쓴다.
  - 현재 가중치에서는 효과가 측정되지 않는다. 그래서 이름을 바꾸더라도 방법의 기여로 내세울 근거는 없다.
- **`DCRC-VAD`는 채택하지 않는다.**
  - 사전등록 조건은 세 가지다: 판정 GO, 조밀 순위·의사 레이블이 각각 4설정 중 3개 이상에서 지지, 커리큘럼 일관.
  - 결과는 조밀 순위 0/4, 의사 레이블 2/4, 커리큘럼 0/4로 하나도 통과하지 못했다.
- **서술형 명칭 제안**(약어 없음): "frozen dual-encoder MIL head with pseudo-label self-training"(동결 이중 인코더 위의 소형 MIL 헤드와 의사 레이블 자기학습).
  - 검증이 실제로 고르는 것은 자기학습의 첫 회차뿐이므로, "multi-round curriculum"이라는 표현은 쓰지 않는 것이 맞다.
  - MIL 위의 의사 레이블 자기학습 자체는 MIST(Feng 등, 2021)와 MSL(Li 등, 2022) 같은 기존 연구에 있다. 따라서 이 명칭만으로는 신규성을 주장하기 어렵다.

## 11. 한계
1. **하이퍼파라미터 출처.**
   - 다음 값은 초기 개발 때 UCF 시험셋 프레임 AUC로 구성들을 비교하며 정한 것이다(`scripts/run_ablation.py`): TC 가중치 0.05, 하위 음성 k=4·0.3, 의사 레이블 커리큘럼, lr 3e-5.
   - 이번 실험은 아무 값도 새로 고르지 않았지만, 이 이력은 F에 유리하게 작용할 수 있다.
   - 그런데도 F의 개선이 일관되지 않았으므로 판정 방향은 바뀌지 않는다.
   - XD에는 UCF 값을 그대로 썼다.
2. 결론은 **현재 가중치의 구성**에 관한 것이다.
   - TC 가중치를 키웠을 때나 자기학습을 1회차로 끝냈을 때의 효과는 이 실험이 답하지 않는다.
   - 확인하려면 검증 전용 탐색을 새로 사전등록해야 한다.
3. 체크포인트 선택에 잡음이 있다. 검증 분할이 작고(UCF 241개), XD SigLIP의 검증 영상 AUC는 약 0.99로 포화에 가깝다.
4. 주 규칙(검증 최고)과 보조 규칙(마지막)의 결론이 다르다. CPL의 AUC 부호와 XD AP 부호가 규칙에 따라 바뀐다. 즉 어느 규칙으로 보고하느냐가 결론을 바꾼다.
5. 규모는 seed 10개, 데이터셋 2개, 특징 쌍 2개다.
   - B/T/C/F는 1단계를 공유하므로, 셀 간 차이에는 1단계 변동이 들어가지 않는다. 2단계 목적함수의 효과만 측정한 것이다.
   - 보조 변형은 1단계가 따로 있어 그 변동까지 포함한다.
6. 추론 시간은 다른 사용자와 공유한 GPU·CPU에서 측정했으므로 참고값이다.
7. **평가 정밀도.**
   - UCF XCB+SigLIP의 기본 모델 B는 평가 정밀도에 따라 AP가 1.1–1.5 달라진다(3절).
   - 사전등록 평가기(단정밀도)로 판정했으며, 반정밀도 값으로는 의사 레이블 효과가 더 작다(5절).
   - 원고의 UCF 수치는 반정밀도 평가에서 나왔으므로, 원고 수치와 이 보고서 수치를 섞어 비교하면 안 된다.
8. **코드 판본.**
   - 학습기와 손실 파일(`train_ucf_pseudo.py`, `train_ucf_unified_lite.py`, `sear/loss/mil.py`)에는 git 마지막 커밋(10d5027) 이후 커밋하지 않은 수정이 있다.
   - 그래서 실행한 코드는 커밋 해시 대신 14절의 파일 해시로 식별한다. 서버와 로컬의 해시는 학습 전에 같음을 확인했다.

## 12. 권장 프레이밍 (원고는 수정하지 않음)
- **새 방법 논문(DCRC-VAD)으로 내세우는 것은 데이터가 뒷받침하지 않는다.**
  - 제안된 두 구성요소 중 조밀 순위는 효과가 없다.
  - 의사 레이블은 UCF에서만 유의하고, 기존 연구에 이미 있는 기법이다.
- **데이터가 뒷받침하는 서술**:
  - 동결 시각-언어 인코더 위에 약 0.5M 파라미터 MIL 헤드와 2단계 학습 일정을 쓰면 강한 WVAD 기준선이 된다.
  - 의사 레이블 자기학습은 검증 선택 기준으로 UCF-Crime AP를 1.2–2.4 올린다. 원고용 반정밀도 평가로는 1.05/0.89다. XD-Violence에서는 보정 후 유의하지 않다.
  - 후반 자기학습 회차는 AUC를 0.9–1.3 깎는다.
  - 조밀 순위 항, 커리큘럼, 보조 위험 헤드는 검증 선택에서 탐지를 개선하지 않는다.
  - 이는 분석·기준선 성격의 기여다. 앞서 "proposed method가 없으면 논문을 제안할 수 없다"는 방침이 있었으므로, 이 서술만으로는 그 방침을 충족하지 못한다.
- **방법 논문을 유지하려면** 새 구성요소를 이번과 같은 절차로 먼저 통과시킨 뒤에 기여로 내세워야 한다: 사전등록, 검증 전용 선택, 2×2 이상 절제, seed 10개.
- **현재 투고 패키지(12쪽 원고)에 대한 주의.** 판정 전 원칙에 따라 원고는 고치지 않았다. 다음 주장은 이번 결과와 충돌하거나 범위를 좁혀야 한다.
  1. 서론·방법에서 "TC-MIL constrains every normal segment"를 기여로 제시한 부분: 측정 가능한 효과가 없다(≤ 0.11 AP).
  2. 기여 1 "objectives carry most of the gain"(UCF, 마지막 규칙):
     - UCF 마지막 규칙에서는 성립한다(+3.0/+5.7 AP, 원고용 반정밀도 평가로는 +3.0/+4.1). 다만 전부 의사 레이블의 효과다.
     - 같은 규칙에서 AUC는 네 설정 모두 0.85–1.34 낮아지고, XD AP는 2.1–3.2 낮아진다.
  3. "On XD-Violence, the final-rule AP gain over UR-DMU recurs":
     - XD 마지막 규칙에서 목적함수를 넣은 F가 B보다 AP가 2.1–3.2 낮다. 따라서 그 이득은 목적함수에서 온 것이 아니다.
     - UR-DMU 비교 자체는 이번 실험 범위 밖이다.
  4. 보조 분기가 탐지에 불필요하다는 원고의 기존 서술은 이번 결과와 일치한다.

## 15. 최종 판정

**NO-GO** — 개선이 불안정하고, 대부분 기존 학습 일정과 기본 헤드로 설명된다.

- 같은 헤드·같은 2단계 일정의 기본 모델 대비 개선(F−B)은 검증 최고 AP에서 4설정 중 2개(UCF)에서만 지지된다. XD 두 설정은 Holm 보정 후 유의하지 않다.
- 개선은 전부 의사 레이블 자기학습에서 나온다. 조밀 순위 손실(TC-MIL)의 고유 효과와 상호작용은 모든 설정에서 0에 가깝다.
- 커리큘럼과 보조 분기도 검증 선택에서 탐지를 개선하지 않는다.
- 따라서 다음과 같이 정리한다.
  - `DCRC-VAD`라는 약어는 채택하지 않는다.
  - TC-MIL은 "dense normal-to-anomaly ranking loss"로 이름을 바꾼다.
  - 보조 분기는 진단용으로만 분류한다.

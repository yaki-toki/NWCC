## 3. 검출력 (`results/e010_summary.json`의 `power`)
- 효과 = 참 차이 / σ이고, 문턱은 δ = 2σ다. 그래서 효과 2σ가 정확히 δ다.
- t 열은 SD_d를 추정한 것을 반영한다. 같은 데이터셋의 두 설정은 추정 SD를 공유하고, 두 데이터셋은 서로 독립이다(변경 기록).
- 네 설정 모두에서 효과가 같은 크기(σ 단위)라고 가정한다. 설정마다 Δ의 잡음은 서로 독립이라고 둔다(아래 민감도 참조).

| 효과 | 절대 크기 (UCF / XD) | 설정 하나에서 Δ ≥ δ (정규 / t) | 채택 (정규 / t) | 나쁨 | 미검출 (정규 / t) | 보류 (정규 / t) |
|---|---|---|---|---|---|---|
| 0 | 0 | 0.023 / 0.040 | 0.00005 / 0.00044 | 0.00005 / 0.00048 | 0.830 / 0.725 | 0.170 / 0.274 |
| 1σ (δ/2) | 0.055 / 0.024포인트 | 0.159 / 0.200 | 0.014 / 0.035 | ≈ 0 | 0.498 / 0.422 | 0.488 / 0.543 |
| 2σ (δ) | 0.109 / 0.049포인트 | 0.500 / 0.524 | 0.312 / 0.360 | ≈ 0 | 0.062 / 0.067 | 0.625 / 0.574 |
| 3σ (1.5δ) | 0.164 / 0.073포인트 | 0.841 / 0.830 | 0.879 / 0.850 | ≈ 0 | 0.001 / 0.002 | 0.120 / 0.148 |

- 거짓 채택은 매우 드물다(t로 0.00044).
- 크기가 δ인 효과는 1/3 정도만 채택된다. 1.5δ면 85% 이상 채택된다.
- 1.5δ는 절대 크기로 UCF 0.16포인트, XD 0.07포인트다.
- 설정 간 상관에 대한 민감도(계획 밖 계산, 정규 근사, 같은 데이터셋 두 설정의 Δ 잡음 상관 ρ, 몬테카를로 200만 회)
  - ρ = 0.5: 귀무 거짓 채택 0.0003, δ 효과 채택 0.33, δ 효과 미검출 0.11
  - ρ = 0.9: 귀무 거짓 채택 0.0007, δ 효과 채택 0.31, δ 효과 미검출 0.18
  - 거짓 채택이 매우 드물고 δ 크기 효과가 1/3 정도 채택된다는 결론은 같다.

## 해석 (판정 밖)
- **seed 잡음이 매우 작다.** 검증 V-AUC가 천장 근처(UCF 95.2–97.5, XD 98.8–99.6)이고, seed 사이의 차이도 작다. 그 결과 δ_d는 0.05–0.11포인트다.
- **채택 규칙이 가려내는 것**: 고정된 검증 영상 위에서 seed를 바꿔도 재현되는 차이다. 문턱은 주로 학습 seed의 잡음을 반영한다(나누기의 몬테카를로 잔여 잡음이 조금 섞인다).
  - 검증 영상 표본이 바뀔 때의 변동은 문턱에 들어 있지 않다.
  - 반분 신뢰도는 설정별로 UCF XCB+XCL 0.59(Δ = −3δ), XD 0.73과 0.67(Δ ≈ −2.6δ)이다. Δ가 δ의 2.5–3배인 설정에서도, 영상 절반으로 재면 부호가 27–41% 바뀐다. UCF XCB+SigLIP(0.39, Δ ≈ 0)은 4절의 단서 때문에 근거로 쓰지 않는다.
  - 따라서 δ_d 근처의 작은 차이로 채택된 설계는, 다른 영상(시험셋)에서 같은 방향이 나온다는 보장이 약하다. 검증 영상 절반(UCF 약 120개, XD 약 296개)에서 본 값을 시험셋으로 외삽한 판단이다. 결정 0004대로 실제 판단은 단계 F의 확정 실험에 기댄다.
- **교차 맞춤을 쓰는 근거가 하나 관찰되었다.** 자기 선택 값과 교차 맞춤 값의 차이가 셀마다 다르다. UCF XCB+XCL에서는 `full`과 `base`의 그 차이가 δ_d의 1.6배이고, 나머지 세 설정에서는 δ_d보다 작다(2절).
- **seed 번호가 공통 요인으로 보인다(계획 밖 관찰).**
  - 같은 데이터셋·셀에서 seed별 편차가 두 특징 쌍 사이에 거의 같이 움직인다. 상관은 UCF `base` 0.996, `full` 0.998, XD `base` 0.999, `full` 0.987이다(각 3점).
  - 독립이라면 네 값이 모두 0.98을 넘을 확률은 약 10⁻⁵ 수준이다(네 집단이 서로 완전히 독립은 아니므로 대략치).
  - `full` − `base`의 seed별 차이도 두 특징 쌍 사이에 양의 상관이다(UCF 0.69, XD 0.96).
  - 원인은 확인하지 않았다. 예를 들어 같은 seed가 초기화나 데이터 순서의 일부를 공유하는지는 재지 않았다.

## 한계
- seed 3개로 잰 표준편차라 거칠다(데이터셋마다 자유도 8). t 계산이 이를 반영하지만, 기준선 자체가 바뀔 수 있다.
- 문턱은 검증 영상을 고정한 채 주로 학습 seed의 잡음을 반영한다(해석 참조).
- 천장 효과가 있다. XD XCB+SigLIP의 V-AUC는 99.4 이상, NS-AUC는 99.96 이상이다. 이 영역에서는 좋아질 여지가 거의 없어, 좋은 설계도 차이가 작게 나온다.
- 검출력 계산은 설정마다 Δ의 잡음이 서로 독립이라고 가정한다(추정 SD의 공유만 반영).
  - 그러나 seed별 편차가 두 특징 쌍 사이에 강하게 상관되어 있다(해석). 그래서 이 가정과 SD_d의 자유도 8은 낙관적이다.
  - 4개 (특징 쌍, 셀) 집단의 분산이 독립이 아니므로, 유효 자유도는 4–6 쪽일 수 있다.
  - 3절의 상관 민감도로 보면 결론은 같다.
- XD의 MC SE / SD_d는 0.23이라 기준 0.25에 가깝다.
- 영상 레이블 지표는 프레임 단위 탐지 성능과 다를 수 있다.

## 실패·재실행과 계획에서 벗어난 점
- 실행은 한 번이었고 실패는 없었다.
- 계획의 측정 항목은 계획대로 계산했다. UCF의 R = 1000 재계산은 계획에 적힌 규칙대로다.
- 구현 검토에서 정한 구체화는 모두 결과를 보기 전에 변경 기록에 적었다.
  - 공유 SD를 반영한 t 검출력
  - 부호 0의 처리(이를 위한 정확한 순위 공식의 V-AUC 포함)
  - 무결성 검사
  - V-pAUC 참고(절반에서 UCF 정상 영상 약 6개)
- 계획에 없던 추가 기술(결과를 본 뒤 계산, 판정에 쓰지 않음)
  - 2절의 자기 선택 값과 낙관
  - 3절의 설정 간 상관 민감도
  - 6절의 `full` − `base` 규칙 대 보기
  - 해석 절의 특징 쌍 사이 seed 상관

## 단계 D 공통 규칙 (관문)
계획의 규칙에 측정한 δ_d를 넣은 것이다. 로컬 로드맵(`docs/ROADMAP.md`)에는 요약을 적는다. 계획에 없던 운영 요건은 "(운영 요건)"으로 표시했다.

1. **조건**: 후보와 기준선을 같은 조건으로 돌린다. 조건은 특징, 분할, 예산, 개발 seed 0·1·2다. 설정 4개 = 데이터셋 2 × 특징 쌍 2.
2. **주 지표**: 교차 맞춤 V-AUC
   - 후보 epoch는 단계 2의 epoch 1–30이다.
   - 나누기는 `stratified_half_splits(labels, R, seed=0)`이고, 분할 파일의 검증 순서에서 만든다.
   - (운영 요건) 나누기는 E010과 같게 고정한다. UCF는 R = 1000(sha256 `7f6a6772…`), XD는 R = 200(sha256 `c7242d82…`)이다.
   - (운영 요건) 어느 실행의 MC SE가 0.25 × SD_d를 넘으면, 그 데이터셋은 후보와 기준선을 함께 R = 1000으로 다시 계산한다. 앞 200개 나누기는 같다.
3. **문턱**: δ_UCF = 0.00109, δ_XD = 0.00049(V-AUC 소수 단위)
   - (운영 요건) 판정은 `results/e010_summary.json`의 정확값으로 한다(0.00109065, 0.00048777).
   - 단계 1을 공유하는 후보에도 같은 문턱을 쓴다.
4. **판정**: Δ = 후보 − 기준선이고, 개발 seed 3개 평균으로 설정 4개에서 잰다.
   - **채택**: 3개 이상에서 Δ ≥ δ_d이고, 나머지에서 Δ > −δ_d
   - **나쁨**: 3개 이상에서 Δ ≤ −δ_d
   - **미검출**: 모두 |Δ| < δ_d
   - **보류**: 그 밖
5. **보조 지표(기술)**: V-AP, NS-AUC, V-pAUC를 함께 적는다. 문턱은 δ^m(5절)이다. 주 지표와 반대 방향으로 2δ^m 이상 움직이면 보고서에 적는다.
6. **계획마다 적을 것**
   - 후보가 기준선과 단계 1을 공유하는지
   - (운영 요건) 기준선을 새로 돌리는지, E003 실행을 다시 쓰는지
   - (운영 요건) `--record`를 쓰는지. 교차 맞춤에는 `record_val_scores.npz`가 필요하다.

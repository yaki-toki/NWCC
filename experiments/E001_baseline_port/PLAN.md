# E001 — 기준 모델 이식과 재현 (로드맵 단계 B)

- 작성 2026-10-02, 실행 전 고정(해시는 `PLAN.sha256`)
- 결과를 본 뒤에는 이 문서를 고치지 않는다. 바뀐 점은 맨 아래 변경 기록에 덧붙인다.

## 질문
- 이전 코드의 기준 모델과 학습 절차를 새 저장소의 정리된 코드로 옮겼을 때, 같은 seed에서 같은 검증 결과가 나오는가.
- 같다면 이후 재설계 비교의 출발점(기준선)을 새 코드로 삼는다.
- 옮기는 대상은 두 가지다.
  - 기준 모델: 동결 특징 + 구간별 MLP 탐지 헤드 + 주의 풀링 영상 로짓
  - 학습 절차: MIL 1단계 → 2단계 자기학습, 검증 선택

## 범위
- **옮기는 것**
  - 특징 캐시 읽기, 검증 분할
  - 탐지 헤드
  - 손실: 영상 로짓 BCE, 최댓값 순위, 희소·평활 정규화, 조밀 순위(이전 "TC-MIL"), 의사 레이블 양성·하위 음성
  - 1단계·2단계 학습기
  - 검증 선택: 검증 영상 AUC, 구간 최댓값
  - 단정밀도 평가기
- **옮기지 않는 것**
  - 보조 위험 헤드(P000에서 탐지 개선 없음)
  - CTAG, 증거 MIL, MSR, CSN, WVC 등 실험용 옵션
  - 시험 선택 분기, 시험 TTA
- **시험셋**: 이 실험은 시험 특징·주석을 읽지 않는다.

## 관문 (B4 이후, 결정적 재현)
- **대상**
  - 모델: "기본 모델"과 "이전 방법(보조 헤드 없음)"
  - seed: 42, 123
  - 설정: UCF XCB+XCL, XD XCB+SigLIP
  - 총 2 × 2 × 2 = 8회
  - 이전 셀 이름(P000): 기본 모델 = `abl_base`, 이전 방법 = `abl_full`
- **비교 기준**: P000 `results/val_selection.csv`의 같은 (구성, 특징, seed) 행
- **비교 항목**: 시작점 검증 영상 AUC, 최고 검증 영상 AUC, 선택 epoch
- **통과 조건**: 8회 모두 AUC 두 값의 |차이| ≤ 1e-4이고 선택 epoch가 같다.
- **불일치 시**
  1. 원인을 찾아 고치거나 기록한다. 원인 후보: 난수 소비 순서, 데이터 순서, 연산 정밀도, 장치 차이.
  2. 원인이 이식 오류가 아님이 확인되면 동등성 검정으로 넘어간다.
     - 방법: 두 단측 검정(TOST)
     - 대상: 개발 seed 0, 1, 2 × 위 2설정 × 두 모델
     - 비교: 새 코드 대 이전 코드를 같은 seed로 실행
     - 지표: 최고 검증 영상 AUC
     - 여유값: δ = 0.3 포인트, 유의수준 0.05
  3. 통과하지 못하면 단계 C로 넘어가지 않는다.
